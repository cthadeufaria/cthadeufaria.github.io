# Atlas Intel GitHub Pages Site

This static site is a demo and data explorer for Atlas Intel. It uses the same v2 artifacts generated by the country pipeline.

## Resources

Generated resources:

- `resources/countries.v2.json` - canonical v2 country records
- `resources/coverage.v2.json` - v2 coverage artifact
- `resources/airports_iata.json` - IATA airport database for globe markers
- `resources/countries_50m.geojson` - Natural Earth boundaries when available

Legacy filenames may exist during migration, but new code should read `countries.v2.json` and `coverage.v2.json`.

## Local Development

Use the repo `.venv` from the root README, generate resources, then serve the site:

```bash
source ../../.venv/bin/activate
cd ../..
python -m scripts.update_all --strict
cd docs/site
python -m http.server 8000
```

Visit `http://localhost:8000`.

## Deployment

GitHub Actions runs the pipeline with Python 3.11, writes v2 resources into this directory, and deploys `docs/site` to GitHub Pages only when generated artifacts differ.
